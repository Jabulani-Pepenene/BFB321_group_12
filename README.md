# BFB321_group_12 Semester Web Application Project
## Project Title
SchoolFeeding360 Web Application Project
## Project Description
SchoolFeeding360 is a Flask-based web application designed to streamline school feeding programme management through inventory tracking, supplier management, meal planning, food waste monitoring, and alerts. It helps improve food resource management, reduce waste, and support efficient, organized school meal operations through a professional, user-friendly interface.
